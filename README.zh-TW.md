# civic-bunko

[English](README.md)

給「115 年地方特考四等・一般民政」考生用的靜態刷題網站，以手機為主。把考選部的官方考古題拆成每回合 5 題的圖像化小卡，讓沒有法學基礎、時間又很少的人也能刷得下去。

**狀態：** 開發初期。筆試日期是 2026 年 12 月 5 日、6 日。

## 功能

- 每回合 5 題官方考古題，作答後立刻回饋
- 每題一句口訣，答對答錯都會出現
- 四色標記：紅＝問法陷阱、綠＝正解、藍＝法條與核心名詞、橘＝官方更正答案
- 新手前置圖卡，例如法律位階
- 每日小任務、考試倒數、集章進度
- 加到主畫面後可離線使用；進度只存在自己的裝置上

## 資料來源

- 題目、答案、更正答案只來自考選部考畢試題查詢平臺公開的 PDF。依著作權法第 9 條，依法令舉行之各類考試試題不得為著作權之標的。
- 法條原文來自全國法規資料庫。
- 解析、口訣、白話改寫由 AI 產生，和官方資料分開存放，畫面上會標示。內容可能有錯，一律以官方答案為準。

## 目錄

```
tools/crawler/   下載官方 PDF 到 data/raw/
docs/plans/      開案書與里程碑
docs/dispatch/   給程式代理的派工單
prototype/       可點擊的介面原型
AGENTS.md        所有程式代理的合約
```

## 開發

爬蟲沒有任何依賴，需要 Node 18 以上：

```bash
node tools/crawler/crawl.mjs --dry-run
```

```bash
node tools/crawler/crawl.mjs
```

```bash
node tools/crawler/verify.mjs
```

爬蟲每次請求至少間隔 2 秒，已下載的檔案不會重抓。

## 聲明

這是個人讀書工具，與考選部無關。角色與插圖皆為原創。
