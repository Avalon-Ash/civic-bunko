# 開案書：小貓之家（多隻小貓＋小屋＋新花色）

- 開案：2026-11-22，主代理 Opus 5.5（Fable 本週見底）。狀態：**等使用者同意**。
- 使用者原話：「小貓可以多幾個槽位？老婆想要多幾隻在畫面上比較開心，也要都能取名」「或許要加一個小屋，在那邊各別換衣服和改名，小貓們也可以在那邊活動。小貓花色也因此要增加一點」「UX/UI 你設計」「這單都給 Agy 做」。
- **期限**：12-01 前全部上線（12-02 起只修錯）。做不完照 §8 的切線縮範圍。
- 一句話：從「一隻貓」變成「一家子貓」：小屋裡看全家、點一隻就幫牠換裝取名，帶幾隻出門陪她。

## 1. 目標
- 最多 **5 隻**小貓（原本那隻＋領養 4 隻），每隻有自己的名字、穿著、毛色。
- 「小貓」分頁改成**小屋**：全家都在房間裡活動（走、坐、理毛、睡、兩隻湊在一起蹭蹭），點一隻就選牠，下面的衣櫥換的是牠。
- 新增 6 種毛色，含花紋（虎斑、三花、賓士、暹羅），讓每隻長得不一樣。
- 今日、集章頁按肉球，**帶出門的那幾隻（最多 3 隻）**一起出來亂跑；答題頁只帶「陪我刷題」的那一隻（不分心）。
- 照「獎勵設計要大方」：第 2 隻一打開就能免費領養；之後幾隻用小魚乾領養，剛好消化她太多的小魚乾（使用者 11-18：錢多多、動力變小）。

## 2. 不能破壞的東西
- 她的進度：`AGENTS.md` §2「使用者資料」。**原本那隻的資料一個欄位都不搬**：名字繼續是 `settings.catName`／`catNameAt`、同步檔的 `cat`，穿著繼續是 `wardrobe.outfit`。新貓全部放新的選填欄位。
- 已核對（2026-11-22）：`parseWardrobe` 重建物件，不認得的欄位會被丟掉、不會讓整份失敗；`owned` 是字串陣列，不認得的 ID 留著（舊版那台只是不扣它的價）。所以新欄位放在 `wardrobe` 裡是安全的；**不准放進 `settings.accessory` 或任何舊版會驗證 ID 的欄位**（`cat-wardrobe.md` §2 的前例）。
- 配件全家共用：買一件，每隻都能穿，**同一件可以好幾隻同時穿**（紙娃娃，不搶）。不做送養、刪除小貓（不做會掉的東西）。
- 新格式要新增 golden 樣本與測試（`save-v7-house.json`、`sync-v2-house.json`），舊樣本不碰。

## 3. 資料（H0 主代理寫型別與紅色測試，H1 實作）

小貓 ID `CatId`：原本那隻固定 `'cat-1'`（不寫進存檔，靠舊欄位表示）；領養的是 `'cat-2'`～`'cat-5'`，照領養順序、產生後不改。用固定編號而不是隨機 ID：兩台各自離線領養第 3 隻，合併後是同一隻（不會多出一隻）。

| 資料 | 存哪 | 同步 | 合併 |
| :-- | :-- | :-- | :-- |
| 領養了哪幾隻 | `wardrobe.owned` 加 `'adopt-cat-2'`…（領養表 `HOUSE.adopt` 在新檔 `constants/house.ts`） | 是（跟著 `owned`） | 聯集（現成） |
| 新貓的名字 | `wardrobe.cats?: Record<CatId, { name?, nameAt? }>` | 是：同步檔選填 `cats: Record<CatId, CatProfile>` | 逐隻 `mergeCatProfile`（現成） |
| 每隻穿什麼（含毛色） | `wardrobe.outfits?: Record<CatId, Outfit>`（原本那隻仍是 `wardrobe.outfit`） | **建議同步**（見 §3.1） | 逐隻比改動時間 |
| 帶出門的是哪幾隻、陪我刷題的是哪隻 | `wardrobe.outing?: CatId[]`、`wardrobe.leader?: CatId` | 否（各裝置自己的） | — |

- 小魚乾：`fishBalance` 的花費多算一項「領養」，價格只在 `HOUSE.adopt`（`spentFish` 讀它；跟配件價格同一處加總，不在畫面另算）。價格：第 2 隻 0、第 3 隻 200、第 4 隻 300、第 5 隻 400（共 900）。H1 先跑 `npx tsx tools/economy/fish-economy.mts`，把結果寫進本節。
- 領養是 `owned` 裡的一筆，不是 `ITEMS` 的配件（配件必須有部位），所以商店清單、試穿、特價都不會看到它。
- 沒取名的新貓顯示預設名（`HOUSE.defaultNames`：二喵、三喵、四喵、五喵）。

### 3.1 要你決定的一件事：穿著要不要跨裝置同步
現在原本那隻的穿著只存本機（ADR 0013）。多隻之後名字會同步、長相不同步，另一台會看到一排白貓、名字對不上長相。
- **建議：同步**。每隻的穿著連同改動時間存成一包，比改動時間、較新的整包留下（同名字的做法）；原本那隻也一起同步（同步檔選填 `outfits`）。要新開 ADR 0018 推翻 0013 的「outfit 只存本機」那一句。
- 不同步的話：H1 少一點工，另一台的長相各自設定。

## 4. 介面（主代理設計，H3 實作）

### 4.1 小貓分頁 → 小屋（手機直向，由上到下）
1. **小屋場景**（約 180px 高）：房間有窗戶（跟著日夜）、地板、坐墊、貓抓板。全家在裡面走、坐、理毛、睡，偶爾兩隻湊在一起蹭蹭（頭上冒 ♥ 泡泡）。點一隻：牠被選中（頭上出現名字牌）、說一句話。
2. **全家名牌列**：橫向一排小頭像＋名字，選中的有外框；最後一格是「＋ 領養」（顯示價格；錢不夠說還差多少；滿 5 隻就不顯示）。
3. **選中那隻的卡片**：名字牌（點了改名，沿用 `CatNameEditor`）、「帶出門」開關、「陪我刷題」（全家只能一隻，選了別隻會自動換過去）。
4. **衣櫥**（現有的試衣間、試穿籤、商店、成就照舊），換的是選中的那隻。試衣間仍黏在上方，顯示選中那隻的全身。

- 領養：點「＋ 領養」開抽屜（`src/ui/kit/` 的自製抽屜），可以先取名、從已經有的毛色挑一個，按「帶牠回家」；牠從小屋的門口走進來。
- 小屋裡同時最多 5 隻在動；畫面不在前景、或捲出畫面時停止動畫（省電）。
- iPad 寬版：左欄小屋＋名牌列＋試衣間（黏住），右欄配件格。
- 手機橫放（高 ≤ 500px）：照現有規則不黏住。
- 320pt 寬：名牌列橫向捲動，不換行。

### 4.2 其他頁
- 今日、集章頁的頭像顯示「陪我刷題」那隻；按肉球，**帶出門的全部出來**（最多 `HOUSE.maxOut` = 3 隻），各走各的動線，叫回家時一起回去。
- 答題頁、看答案頁：只有「陪我刷題」那隻在進度條上，想太久的提示也只有牠。模擬考照舊不出來。
- 套裝效果每隻看自己的穿著。多隻同時出來時避免太吵：
  - 發出聲音的（哞、說話泡泡、夢話）同一時間只有一隻，兩次至少隔 `HOUSE.voiceGapMs`。
  - 改動卡片的效果（焦痕、劈歪、結冰、抓痕）全家共用同一個上限，照現有的數字（焦痕最多 5 處），同一張卡片同一時間只受一種效果。
- 說話：每隻用自己的名字；台詞包照舊共用。

## 5. 新毛色（H2）
| ID | 名稱 | 樣子 | 價格 |
| :-- | :-- | :-- | :-- |
| `fur-milktea` | 奶茶 | 淺奶茶色素色 | `PRICE.m` |
| `fur-tabby` | 虎斑 | 棕底深棕條紋（額頭 M 字、背、尾巴環） | `PRICE.xl` |
| `fur-silver` | 銀虎斑 | 銀灰底黑灰條紋 | `PRICE.xl` |
| `fur-tuxedo` | 賓士 | 黑底，白口鼻、白胸口、白手套 | `PRICE.xl` |
| `fur-calico` | 三花 | 白底，橘與黑的大塊斑 | `PRICE.rare` |
| `fur-siamese` | 暹羅 | 奶油色身體，深色臉、耳朵、腳、尾巴 | `PRICE.rare` |

- 做法：毛色從「只有色票」擴充成「色票＋選填的花紋層」，花紋畫在頭、身體、尾巴裡面（用現有輪廓裁切，不超出），條紋與斑塊沿用娃娃裝 `KigurumiTheme.pattern` 的畫法。花紋表只在一處（毛色的 art 表），`Cat`、`CatBody` 讀它。
- 必須成立：頭像 64×64、每種姿勢、面向左右、日夜、穿連身裝（身體花紋被衣服蓋住、臉露出來的部分照畫）。
- 驗收：`tools/gallery/cat-gallery.mts` 加這 6 種的列，主代理看截圖；`catBody.test.ts` 加「花紋不超出輪廓」。新增 6 件後重跑小魚乾試算。

## 6. 架構重點（不做耦合）
- 「有幾隻、誰是誰」只在一個 System（`systems/house.ts`）；畫面只經 `selectors/house.ts` 讀、`UICommand` 寫（領養、改名、換裝、帶出門、陪我刷題）。
- 現在所有「只有一隻」的地方要改成讀小貓 ID：`petStore`（單例 → 依 ID）、`PetLayer`、`PetRunner`、`useCatHint`、`CatHome`、`catSituation` 的名字、`currentOutfit`、試衣間。
- 原本那隻的讀寫集中成一個「cat-1 讀舊欄位、其他讀新欄位」的轉接函式，只寫在 `systems/house.ts` 一處，其他地方不判斷 `id === 'cat-1'`。
- 數字（最多幾隻、出門幾隻、領養價格、聲音間隔、預設名字）只在 `constants/house.ts`。

## 10. 什麼時候停下來問
- 任何改動會讓舊 golden 讀不回來、或需要改既有欄位意義。
- 花紋或小屋場景被使用者退一次（先要參考圖）。
- 多隻出門在手機上卡頓（掉到明顯不順），要減少出門隻數或關掉某些效果。
