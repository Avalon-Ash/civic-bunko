# civic-bunko 開案書

開案：2026-11-15（Fable 5.2）。狀態：**待使用者確認**，確認前不派工。

## 1. 目標

讓一位零法學基礎、容易分心的考生，在 2026-12-05、12-06 的「115 年地方特考四等・一般民政」前，每天用 iPhone／iPad 花零碎時間刷官方考古題，並且看得懂為什麼。

開案當天距離筆試 **20 天**。因此：
- 第 3 天就要有能刷題的版本上線，之後每天變好一點。
- 做不完的砍功能，不砍「官方題庫正確」與「一次只看一點點」。

### 題庫範圍

113–115 年普通考試（3 份）＋ 113–114 年地特四等（2 份），上表五科（115 年普考一般民政實測也是這五科，見 `docs/moex-recon.md`）。
估計測驗題約 900 題（實際數字由爬蟲產出）。初等考試不收。

## 2. 使用者與介面準則

使用者是專案擁有者的太太（ISFP，圖像型學習者）。她自己用 AI 做過一版複習工具，其中「口訣＋陷阱提醒」的回饋方式她吃得下去，其餘不堪用。

| 特質 | 設計上的落實 |
| :-- | :-- |
| 要靠圖像才能吸收抽象概念 | 每個考點配一張小圖（角色演出情境、對比圖、流程圖）；文字是圖的說明，不是主體 |
| 靠口訣快速理解 | 每題答對答錯都給一句口訣＋一句陷阱提醒，不寫成段落解析 |
| 視覺學習、怕大量文字 | 一個畫面一件事；題幹之外預設只多一句話；字數上限寫進資料驗證 |
| iPhone／iPad 重度使用 | 底部分頁列、大標題、底部抽屜、左右滑換題、44pt 觸控區、safe-area、可加到主畫面離線用 |
| 喜歡圓潤療癒、集章回饋 | 粉彩、大圓角、原創小角色、每回合蓋一個章；答錯不扣分、不出現紅色大叉 |

四色語意（沿用使用者偏好的解析手冊）：紅＝問法陷阱、綠＝正解、藍＝法條與核心名詞、橘＝官方更正。

## 3. 產品藍圖

底部四個分頁：

1. **今日**：倒數天數、今天的 3 個小任務（每個 5 題，約 3 分鐘）、本週集章卡。打開就能按「開始」。
2. **圖卡**：新手前置觀念，一張一個觀念，點了才展開。第一批：法律位階（憲法＞法律＞命令）、中央與地方、行政處分是什麼、訴願到行政訴訟的路線、期間怎麼算。
3. **刷題**：自選科目／考點／年度；或「弱點回合」「高頻回合」「只刷錯題」。
4. **集章**：各科進度、弱點考點排行、連續天數。

### 一題的呈現（由少到多）

1. 題幹（紅標問法、藍標關鍵詞）＋四個大選項。可切「白話版」：把題目改寫成生活情境。
2. 作答後（答對答錯都一樣）：正解變綠＋角色小圖＋**口訣**（≤ 40 字）＋**陷阱提醒**（≤ 30 字）。
3. 點「看每個選項」：底部抽屜，逐選項一行（≤ 50 字）＋法條條號。
4. 點條號：顯示條文原文（來自全國法規資料庫）。

### 快刷模式（使用者 11/15 追加，主要用法）

她現在要靠大量刷題記憶，像語言學習 App 那樣一題接一題。

- 開始前一張「回合設定」抽屜：選科目、選題數、開關快刷。題數用貓掌按鈕（5／10／20／30／50）加上加減鈕微調，上一次的設定會記住。
- 快刷開啟時：答對只閃一行口訣就自動跳下一題；答錯才停下來顯示完整口訣卡（圖＋口訣＋陷阱），按了才繼續。
- 畫面上方顯示連對數；中途可以隨時結束，已答的題照樣記錄。
- 回合結束：答對率、這回合錯的題一鍵重刷。

### 題庫總數與可玩性（使用者 11/15 追加）

- 題庫總數要看得到：今日（題庫共 N 題・已刷 M 題）、回合設定（這個範圍有 N 題可刷）、集章（每科已刷／總題數）。
- 介面要有互動動態，不能死氣沉沉：角色點了會回應、答對噴貓掌、連對里程碑橫幅、進度條上的貓會走、數字滾動、蓋章砸下來。清單在 `docs/dispatch/P1e-2a-ui.md`「可玩性」。全部尊重減少動態效果的系統設定，只用 CSS，不加動畫套件。

### 回合組成

- 題數由使用者決定（預設 10 題，範圍 5–100）；答完蓋章。「今日任務」仍是每個 5 題的小任務。
- 排程用簡化的間隔複習：答錯的題 1 天、3 天、7 天後回來；連對兩次才畢業。
- 「高頻回合」依考點出現次數；「弱點回合」依個人答錯率。
- 考前 3 天自動切成衝刺模式：只出錯題＋高頻考點，不出新題。

### 時程控管（產品內）

- 倒數以 2026-12-05 為準，12-06 當天顯示第二天科目。
- 每日任務量依剩餘天數與未刷題數自動算，使用者只看到「今天 3 回合」。
- 依考試節次排科目權重：全測驗的行政法、行政學、法學知識優先；地方自治次之；國文測驗與英文最後。

## 4. 架構

```
tools/crawler/      考選部下載 → data/raw/（PDF，含 sha256 清單）
tools/parser/       PDF → data/official/<年度>-<考試>-<科目>.json
tools/laws/         全國法規資料庫 → data/laws/<法規>.json
tools/enrich/       加工批次的輸入包與合併器 → data/enrich/<題目ID>.json
tools/validate/     schema、字數上限、官方欄位雜湊、法條引用存在性
src/                Vite + React + TypeScript + 純 CSS token，打包時合併 official + enrich
.github/workflows/  lint → validate → test → build → Pages
```

- **技術選型**（實際採用）：Vite 6＋React 19＋TypeScript strict；樣式是純 CSS 與 `src/theme.css` 的 token，動態效果只用 CSS，沒有用 Tailwind、motion 或任何動畫套件；離線用自己寫的 `public/sw.js`，沒有用 `vite-plugin-pwa`。執行期相依只有 `react`、`react-dom`。爬蟲與解析用 Node（tsx）＋`pdfjs-dist`，不進 bundle。
- **爬蟲獨立**：只在本機手動執行，產物提交進 repo；CI 不連考選部。每次請求間隔 ≥ 2 秒，已有的檔案不重抓。
- **官方層與加工層分開**：官方層由流水線產生並記錄雜湊，加工層怎麼錯都不會汙染題目與答案。
- **法條有本機副本**：解析引用的條號要在 `data/laws/` 查得到，驗證腳本自動檢查，減少模型憑印象寫錯條號。
- **進度存裝置，另可同步**：localStorage；匯出／匯入 JSON；另可用「同步碼」把進度與每日題數同步到使用者自己的私人 GitHub repo（`docs/sync-setup.zh-TW.md`）。設定類（配件、卡片已看、模擬考成績）只存裝置，不同步。
- 考選部試題依著作權法第 9 條不屬著作權標的，可公開放在 GitHub。

### App 架構：ECS＋SSOT（使用者 11/15 指定）

題庫量大、之後還會換題庫或加考試，所以資料、邏輯、畫面三者分開。

```
src/core/types.ts          所有型別的唯一定義
src/core/constants/*.ts    題數範圍、字數上限、複習間隔、考試日期、四色語意（不寫魔術數字）
src/core/world.ts          實體 ID 與各 component store 的容器
src/core/bus.ts            事件匯流排（answered、roundFinished、bankLoaded…）
src/core/commands.ts       UICommand：畫面寫入狀態的唯一入口
src/components/            純資料，以實體 ID 為鍵，不含邏輯
src/systems/               純函式，讀寫 component，彼此只透過 bus 溝通
src/selectors/             畫面讀取狀態的唯一入口（唯讀）
src/ui/kit/                自製元件：Sheet、Dialog、Toast、Stepper、Segmented、Chip…
src/ui/screens/            四個分頁與回合畫面，只呼叫 selectors 與 commands
src/theme.css              色彩、圓角、字級的唯一定義
```

| 實體 | Component（純資料） |
| :-- | :-- |
| 題目 | `Official`（題幹、選項、答案、來源）、`Enrich`（口訣、陷阱、圖、標記）、`TopicRef`、`Progress`（作答次數、連對、下次到期日） |
| 考點 | `TopicInfo`（名稱、所屬科目）、`TopicStats`（出現次數、個人答錯率） |
| 圖卡／申論卡 | `CardContent`、`Progress` |
| 回合 | `RoundConfig`（科目、題數、模式）、`RoundState`（題目序列、目前位置、連對數） |

| System | 職責 | 擁有的欄位 |
| :-- | :-- | :-- |
| `BankLoader` | 依 `data/banks.json` 載入題庫包到 `Official`／`Enrich` | `Official`、`Enrich` |
| `Selection` | 依 `RoundConfig` 組出題目序列（科目、高頻、弱點、錯題、到期） | `RoundState.queue` |
| `Round` | 推進回合、判定對錯、連對數 | `RoundState` 其餘欄位 |
| `Scheduling` | 間隔複習到期日 | `Progress.due`、`Progress.streak` |
| `Stats` | 考點統計、弱點排行 | `TopicStats` |
| `Daily` | 倒數、今日任務、集章 | `Daily*` |
| `Persistence` | 進度存取 localStorage、匯出匯入 | 無（只序列化） |

規則：
- 一個欄位只有一個擁有者 System；其他 System 要改就發事件給它。
- 畫面元件不直接讀寫 store、不放業務邏輯；System 不碰 DOM。這樣 System 可以用 `node:test` 直接測，不需要瀏覽器。
- **題庫是可抽換的包**：`data/banks.json` 登記每個題庫（ID、名稱、科目、資料路徑）；題目紀錄帶 `bankId`。之後加別的考試或別的年度只要加一個包，不改程式。
- **不用瀏覽器彈窗**：`alert`、`confirm`、`prompt`、`window.open`、`target="_blank"` 一律禁用（lint 規則擋）。所有抽屜、對話框、提示都用 `src/ui/kit/` 的自製元件，畫在頁面內。

### 資料格式（摘要）

```ts
// data/official
{ id, year, exam: "local4" | "general", subject, no,
  stem, options: {A,B,C,D}, answer: ["B"], 
  correction: null | { original, note, sourceUrl },
  source: { url, downloadedAt, sha256 }, parseStatus: "ok" | "needs_review" }

// data/enrich
{ id, topic: ["行政程序法/期間"], askType: "pick_wrong" | "pick_right" | ...,
  marks: [{ field: "stem", start, end, color: "red" | "blue" }],
  mnemonic, trap, scene: "圖像情境的代號，對應角色小圖", plain, keywords: [{ term, gloss }],
  options: { A: { verdict, why, lawRef: { law, article } | null }, ... },
  model, generatedAt, reviewed: false }
```

## 8. 什麼時候停下來問使用者

- 考選部平臺擋自動下載或改版，需要改成手動下載時。
- 任一科 `needs_review` 超過該科題數 5%。
- 加工批次抽樣錯誤率超過 10%（代表模型不適合，要換做法）。
- 任何 commit 以外的 Git 操作、開 GitHub repo、開 Pages、公開或私人的選擇。
- 時程落後里程碑超過 1 天，需要砍範圍時（附建議砍哪一項）。

## 9. 現況與和原計畫的差異（2026-11-16 更新）

資料格式以 `src/core/types.ts` 為準，§4 的「資料格式（摘要）」是開案時的草稿。

### 已上線
- 題庫：25 份官方試卷、925 題測驗題、16 題申論／作文題；27 部法規副本。925 題全部有口訣、陷阱、白話、逐選項說明與圖。

- 圖卡 55 張：觀念 31（新手 5、行政學 13、國文 3、高頻考點 10）、新法 8、申論與作文架構 16（地方自治 10、國文 6）。列表可依科目篩選。

- 今日：倒數、每日 15 題三個小任務；集章：全部達標才蓋章、集章換小貓配件。
- 同步（私人 repo＋同步碼）：作答進度、每日題數、看過的卡片、模擬考歷次成績。匯出匯入、新版提示、加到主畫面引導、日夜主題。
- 離線：打包時產生資產清單 `precache.json`，App 啟動後把這一版的所有檔案（含 27 部法規全文）補進快取，並清掉舊版殘留（`src/data/offline.ts`）。
