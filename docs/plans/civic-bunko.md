# civic-bunko 開案書

開案：2026-11-15（Fable 5.2）。狀態：**待使用者確認**，確認前不派工。

## 1. 目標

讓一位零法學基礎、容易分心的考生，在 2026-12-05、12-06 的「115 年地方特考四等・一般民政」前，每天用 iPhone／iPad 花零碎時間刷官方考古題，並且看得懂為什麼。

開案當天距離筆試 **20 天**。因此：
- 第 3 天就要有能刷題的版本上線，之後每天變好一點。
- 做不完的砍功能，不砍「官方題庫正確」與「一次只看一點點」。

## 2. 使用者與介面準則

使用者是專案擁有者的太太（ISFP，圖像型學習者）。她自己用 AI 做過一版複習工具，其中「口訣＋陷阱提醒」的回饋方式她吃得下去，其餘不堪用。

| 特質 | 設計上的落實 |
| :-- | :-- |
| 要靠圖像才能吸收抽象概念 | 每個考點配一張小圖（角色演出情境、對比圖、流程圖）；文字是圖的說明，不是主體 |
| 靠口訣快速理解 | 每題答對答錯都給一句口訣＋一句陷阱提醒，不寫成段落解析 |
| 視覺學習、怕大量文字 | 一個畫面一件事；題幹之外預設只多一句話；字數上限寫進資料驗證 |
| iPhone／iPad 重度使用 | 底部分頁列、大標題、底部抽屜、左右滑換題、44pt 觸控區、safe-area、可加到主畫面離線用 |
| 喜歡圓潤療癒、集章回饋 | 粉彩、大圓角、原創小角色、每回合蓋一個章；答錯不扣分、不出現紅色大叉 |

四色語意（沿用使用者偏好的解析手冊）：紅＝問法陷阱、綠＝正解、藍＝法條與核心名詞、橘＝官方更正。

## 3. 產品藍圖

底部四個分頁：

1. **今日**：倒數天數、今天的 3 個小任務（每個 5 題，約 3 分鐘）、本週集章卡。打開就能按「開始」。
2. **圖卡**：新手前置觀念，一張一個觀念，點了才展開。第一批：法律位階（憲法＞法律＞命令）、中央與地方、行政處分是什麼、訴願到行政訴訟的路線、期間怎麼算。
3. **刷題**：自選科目／考點／年度；或「弱點回合」「高頻回合」「只刷錯題」。
4. **集章**：各科進度、弱點考點排行、連續天數。

### 一題的呈現（由少到多）

1. 題幹（紅標問法、藍標關鍵詞）＋四個大選項。可切「白話版」：把題目改寫成生活情境。
2. 作答後（答對答錯都一樣）：正解變綠＋角色小圖＋**口訣**（≤ 40 字）＋**陷阱提醒**（≤ 30 字）。
3. 點「看每個選項」：底部抽屜，逐選項一行（≤ 50 字）＋法條條號。
4. 點條號：顯示條文原文（來自全國法規資料庫）。

### 回合組成

- 一回合固定 5 題；答完蓋章。可以連續再來一回合，但不強迫。
- 排程用簡化的間隔複習：答錯的題 1 天、3 天、7 天後回來；連對兩次才畢業。
- 「高頻回合」依考點出現次數；「弱點回合」依個人答錯率。
- 考前 3 天自動切成衝刺模式：只出錯題＋高頻考點，不出新題。

### 時程控管（產品內）

- 倒數以 2026-12-05 為準，12-06 當天顯示第二天科目。
- 每日任務量依剩餘天數與未刷題數自動算，使用者只看到「今天 3 回合」。
- 依考試節次排科目權重：全測驗的行政法、行政學、法學知識優先；地方自治次之；國文測驗與英文最後。

## 4. 架構

```
tools/crawler/      考選部下載 → data/raw/（PDF，含 sha256 清單）
tools/parser/       PDF → data/official/<年度>-<考試>-<科目>.json
tools/laws/         全國法規資料庫 → data/laws/<法規>.json
tools/enrich/       加工批次的輸入包與合併器 → data/enrich/<題目ID>.json
tools/validate/     schema、字數上限、官方欄位雜湊、法條引用存在性
src/                Vite + React + TypeScript + Tailwind，打包時合併 official + enrich
.github/workflows/  lint → validate → test → build → Pages
```

- **技術選型**：沿用 Kyoto-Bunko 的 Vite＋React 19＋TypeScript＋Tailwind 4＋motion（手勢與彈簧動畫）；加 `vite-plugin-pwa` 做離線。爬蟲與解析用 Node（tsx）＋`pdfjs-dist`，和 App 同一套工具鏈但不進 bundle。
- **爬蟲獨立**：只在本機手動執行，產物提交進 repo；CI 不連考選部。每次請求間隔 ≥ 2 秒，已有的檔案不重抓。
- **官方層與加工層分開**：官方層由流水線產生並記錄雜湊，加工層怎麼錯都不會汙染題目與答案。
- **法條有本機副本**：解析引用的條號要在 `data/laws/` 查得到，驗證腳本自動檢查，減少模型憑印象寫錯條號。
- **進度只存裝置**：localStorage；提供匯出／匯入 JSON 讓 iPhone 與 iPad 之間搬進度。
- 考選部試題依著作權法第 9 條不屬著作權標的，可公開放在 GitHub。

### 資料格式（摘要）

```ts
// data/official
{ id, year, exam: "local4" | "general", subject, no,
  stem, options: {A,B,C,D}, answer: ["B"], 
  correction: null | { original, note, sourceUrl },
  source: { url, downloadedAt, sha256 }, parseStatus: "ok" | "needs_review" }

// data/enrich
{ id, topic: ["行政程序法/期間"], askType: "pick_wrong" | "pick_right" | ...,
  marks: [{ field: "stem", start, end, color: "red" | "blue" }],
  mnemonic, trap, scene: "圖像情境的代號，對應角色小圖", plain, keywords: [{ term, gloss }],
  options: { A: { verdict, why, lawRef: { law, article } | null }, ... },
  model, generatedAt, reviewed: false }
```

## 8. 什麼時候停下來問使用者

- 考選部平臺擋自動下載或改版，需要改成手動下載時。
- 任一科 `needs_review` 超過該科題數 5%。
- 加工批次抽樣錯誤率超過 10%（代表模型不適合，要換做法）。
- 任何 commit 以外的 Git 操作、開 GitHub repo、開 Pages、公開或私人的選擇。
- 時程落後里程碑超過 1 天，需要砍範圍時（附建議砍哪一項）。
