第一輪派工單是 `docs/dispatch/CC4a-props.md`（畫風、顏色、座標、指令、固定三條全部照舊）。你上一輪畫的 7 個道具已經併進來了，審圖的人對其中 3 個有意見，這一輪**只改這 3 個**（`src/ui/kit/comic/props.tsx` 的 `PROP_ART`），其他 16 個不動。

| id | 審圖意見（約 40px 大時） | 怎麼改 |
| :-- | :-- | :-- |
| `torn-paper` | 兩半各有一枚完整的紅章，看起來像兩張各自破邊的公文 | 讓**同一枚紅章**和同一兩行字**跨過裂口**：章被撕成左半、右半，各在一邊；兩半的橫線高度對齊。一看就知道是同一張紙被撕開 |
| `handcuffs` | 深色模式下兩個環中間的短鏈看不清楚，像兩個分開的金屬環 | 鏈節加粗（用 `stroke` 外框＋`--acc-silver` 填色的 2–3 個橢圓鏈節，每個至少 6×4），兩個環靠近一點，鏈條明顯連著兩環 |
| `ballot-box` | 票上的紅圈像信封的封蠟，箱子容易看成郵筒 | 票上改成**勾選框**：一個小方框裡一個打勾（用線畫，`--acc-coral`），不用圓形；票要明顯插進箱頂的投入口一半。箱子正面可以加一個橫的標示條（不寫字） |
