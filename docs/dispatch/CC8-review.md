# CC8 審圖：4 個新道具與 16 張申論卡漫畫

你是審圖的人，**只讀不改任何檔**。不要提問；看不到圖或做不了的，寫進最後的「阻礙」一行，不要略過。

## 背景
App 的圖卡有「四格漫畫」：小貓當演員，加一兩樣道具和一面舉牌，讓考生看圖就想起考點（`docs/plans/comic-cards.md` §2）。這批是**申論題的答題骨架卡**：四格一律起承轉合，「起」放破題或定義、「承」放制度或要點、「轉」放問題、爭議或例外、「合」放結論或對策。國文卡畫的是「這一段要寫什麼」，不是範文。

格子的字只能取自卡片原文，不能改；能改的只有：構圖（一隻貓＋兩樣道具／兩隻貓面對面＋一樣道具／大道具＋一隻貓／三隻貓＋一樣道具）、角色、姿勢（站、走、跑、坐、跳、踉蹌、趴）、表情（開心、慌、睏）、面向、道具、舉牌（必須是那格那句話的一部分）、換一句卡片裡的其他句子。

角色看毛色和帽子分辨：灰貓戴領帶與單片眼鏡＝機關、橘貓戴毛帽＝人民、銀虎斑戴學士帽＝公務員、暹羅貓戴貝雷帽＝民意代表（議員）、三花貓綁頭巾＝地方政府。

能用的道具（建議換道具時只從這裡挑）：印章、公文、罰單、信封、沙漏、日曆、法院、辦公大樓、路面坑洞、壞掉的路燈、靶心、大門、撕破的紙、橡皮擦、一疊硬幣、剪刀、手銬、投票箱、皇冠、天秤、柵欄、雨傘、放大鏡、考卷、房子、公園長椅、錢袋、拱橋、手機、魚、虎鯨。

## 要回答的
1. 新道具在約 40px 大時，**一眼認得出來**是它的名稱嗎？哪個看不出來、會被看成別的東西？
2. 每張漫畫的每一格，圖和那格的字、舉牌，**意思對得上**嗎？有沒有哪格的圖會讓人記錯（誰對誰、動作方向、道具暗示了相反的意思）？
3. 配對遊戲時舉牌和字會遮起來、只看圖：**同一張卡裡有沒有兩格的圖幾乎一樣**、分不出是哪一格？
4. 版面問題，包括深色模式：字被截斷、東西重疊、看不清楚。

## 回報格式
每個問題一行：`[必改|建議] 卡片 id・第幾格（起承轉合）：問題 → 建議怎麼改（只用上面能改的東西）`。只列你在圖上看到的；沒有問題就寫「沒有」。不要寫稱讚。最後兩行寫你打開了哪幾張圖、阻礙（沒有就寫沒有）。
