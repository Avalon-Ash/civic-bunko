第一輪的 12 個道具已經 commit。審圖者（另一個模型）看了截圖，說下面三個在小尺寸（約 40px）時容易誤認。**只改這三筆**，其他九筆一行都不動。規則照 `docs/dispatch/CC1-art-props.md`（畫風、只用 token、**圖裡不准有任何文字或數字**、viewBox 64、底邊貼 y=60、只改 `src/ui/kit/comic/props.tsx`、同樣五個指令）。

| id | 審圖意見 | 這次要畫成 |
| :-- | :-- | :-- |
| `ticket` | 看起來像粉紅警告標籤或收據 | 直式單子：上緣撕下來的鋸齒；上方一條**紅色抬頭條**；中間一個較小的粗驚嘆號；下方一個**長方形金額框**（框裡兩三條粗短橫線代表數字）；右下一個紅色圓印。整體像「開給你的單子」 |
| `pothole` | 像交通錐旁一灘油 | 一段灰色路面，中間是**不規則的破口**（鋸齒邊緣），破口一側看得到**內壁**（深一點的色帶），周圍有幾塊碎裂的路面小塊；交通錐縮小、退到後方右側。破口顏色不要用近黑，用 `--acc-shade` 加一圈 `--acc-silver` 的破碎邊 |
| `lamp` | 像有電火花的檯燈 | **高**的路燈：燈桿細長（從 y=60 到 y≈8），底座小；頂端彎出去的燈頭，燈罩**明顯缺一角**（大塊缺口，不是細線）；只留**一個**較大的火花（星形或鋸齒閃電），用 `--acc-gold` |

另外：在深色模式下，道具的棕色外框會融進深色背景；這三筆的填色請選亮一點的 token（例如路面用 `--acc-silver`、燈桿用 `--acc-sky` 或 `--acc-silver`），不要用 `--acc-wood`、`--acc-night`、`--acc-shade` 當大面積的主色。
