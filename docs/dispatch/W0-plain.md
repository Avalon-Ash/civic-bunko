無人值守。讀完本檔與必讀檔案後直接動手，不要寫計畫、不要等確認。

- **目標**：她刷題時按「白話」，每一題（英文題除外）都看得到白話。現在有 79 題是 `plain: null`，畫面上沒有「白話」按鈕，她以為是漏了。

## 要做的事

`docs/dispatch/W0-plain.targets.txt` 列了 79 個題目 ID（一行一個）。逐題把 `data/packs/local4-civil/enrich/<PaperId>.json` 裡那一題的 `plain` 從 `null` 改成一句白話（題目 ID 去掉 `-qNN` 就是 PaperId）。題目原文、選項、官方答案在 `data/packs/local4-civil/official/<PaperId>.json`。

**只改這 79 題的 `plain`**。其他欄位、其他題目、檔案層的 `model`／`generatedAt` 一律不動；JSON 縮排與鍵的順序維持原樣。

## 怎麼寫（每句 ≤ 60 字，`npm run validate` 會檢查）

- **行政學、地方自治、行政法**：把題目改成白話的問句，可以用生活場景。像朋友在講話，不用術語解釋術語。例：「市議會通過『亂丟垃圾要罰錢』的規定。發布前要先送中央做什麼？」
- **國文，引文是文言文**：寫這段文言的白話大意，最後可以接一句題目在問什麼。例：「韓非說：國家強不強，靠的是內政有沒有法度，不是對外耍聰明。題目問這段的主旨。」
- **國文，引文是白話文的閱讀題**：一句話講這段在說什麼，再接一句題目在問什麼。例：「作者說偏鄉不是沒人願意去，是制度留不住人。題目問作者的看法。」
- **國文，字詞、成語、題辭題**：白話講題目在考什麼。例：「四個句子裡挑出用詞最恰當的一句。」
- **絕對不能洩漏答案**：白話不能指向正確選項，也不能把某個選項的關鍵字當成結論寫進去。
- 意思要跟原題一致：不能改掉題目的條件或反向問法。題目問「何者錯誤」，白話也要問「哪個說錯了」。
- 繁體中文、臺灣用語，不用簡體字。
