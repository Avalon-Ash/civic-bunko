# 考選部考畢試題平臺探勘（P0）

查核日期：2026-11-15。以 `curl` 實測，以下每一條都看過回應。

## 查詢頁

- `GET https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?y=<西元年>&e=<考試代碼>`
  直接回傳該考試全部類科的列表（HTML，約 1.5 MB），不需要 POST 或 `__VIEWSTATE`。
- 只帶 `?y=<西元年>` 會回傳該年度的考試下拉選單（`<option value="考試代碼">`）。

## 列表結構

- 每個類科是一個 `<label for="ctl00_holderContent_chk_<考試代碼>_<類科代碼>">等級_類科名稱</label>`。
  115080 實測：`普通考試_一般民政`，類科代碼 `402`。
  地特兩場的等級文字與類科代碼**尚未確認**，由爬蟲從列表找出「四等」且類科名稱為「一般民政」的那一筆，印出來。
- 類科之下依序是科目名稱，接著是檔案連結。每個連結在 HTML 裡出現兩次（要去重複）。

## 檔案網址

`https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?t=<類型>&code=<考試代碼>&c=<類科代碼>&s=<科目代碼>&q=1`

| `t` | 連結文字 | 內容 |
| :-- | :-- | :-- |
| `Q` | 試題 | 試題 PDF |
| `S` | 答案 | 測驗題標準答案 PDF |
| `M` | 更正答案 | 更正答案 PDF（有更正才有） |

HTML 裡的 `&` 寫成 `&amp;`，要還原。
