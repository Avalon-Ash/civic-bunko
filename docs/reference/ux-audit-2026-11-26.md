## 量法
開發機 `npm run dev`，內建瀏覽器 375×812（手機），**空白存檔**（沒作答、沒同步）。每個分頁點開後，列出主內容的直屬區塊（高度＋開頭文字）。她的真實存檔會更長（弱點排行、歷次成績、已買的配件）。

## 任務引導：找到的具體問題
1. **今日頁的「今日任務」卡，點了一律去「小貓」分頁**（`src/ui/screens/TodayScreen.tsx:311`，`onClick={onGoCat}`），不管任務是什麼。任務池（`src/core/constants/wardrobe.ts:321` `QUESTS`）有五種：完成一回作答、錯題重做、刷弱點或高頻、看一張新圖卡、交一份模擬考。例：今天的任務是「看一張新圖卡」，點下去卻到衣櫥。
2. **「任務」這個詞有三套**，名字相近、位置分散：
   - 今日頁「今天的 3 個小任務」：每科 5 題，三個做完蓋章（`MISSION_SIZE`、`DAILY_GOAL_QUESTIONS`，`constants/daily.ts`）。
   - 今日頁和小貓頁的「今日任務」：每天一個，給小魚乾（`QUESTS`）。
   - 小貓頁的「今天刷了 N 題」與 5／15／30 題關卡：給小魚乾。
   她看到「任務」不知道指哪一套，也不知道完成哪一個要按哪裡。
3. 設定類（音效、天氣、檢查更新、版本）放在今日頁底部；同步與備份放在集章頁。設定散在兩頁。
