## 政策型申論卡的查證來源（2026-11-16）

沒有法條可對照的三張申論卡，內容依下列公開資料核對。數字是資料發布當時的統計，之後會變。

- **地方創生的成果**（113 普考）：行政院「地方創生 3.0」重要政策頁、行政院院會「打造永續共好地方創生計畫（2025–2028 年）」、工商時報〈5 年砸 60 億 國發會曝地方創生 2.0 推動成果〉、中時新聞網 2024-04-16〈地方創生成果績效評估機制 國發會：擬逐步建立〉（監察院要求改善；青年留返鄉 1.1 萬人次、工作機會 1.2 萬人次是國發會自己的統計）。108 年 1 月核定「地方創生國家戰略計畫」、五大推動戰略、110–114 年「加速推動地方創生計畫」見國發會簡報。
- **跨域治理的障礙**（115 普考）：呂育誠〈跨域治理概念落實的挑戰與展望〉（文官制度季刊 4 卷 1 期）、趙永茂〈台灣府際關係與跨域管理〉（政治科學論叢 18 期）、國發會委託研究報告；法條依 `data/laws` 的地方制度法第 21、24、24-1 條。
- **地方自治三個階段**（113 地特四等）：年代依題目本身與法規沿革（1994 年省縣自治法、直轄市自治法；1997 年第四次修憲；1999 年地方制度法；2010 年縣市合併改制；2014 年山地原住民區）。
