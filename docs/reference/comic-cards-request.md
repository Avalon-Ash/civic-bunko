## 主代理的判讀
- 下面那份規格是 AI 依她的口述與一段 App 錄影產生的。它列的「原始教材重點」逐字就是 App 現有圖卡的標題、hook 與 faces（例：`concept-admin-act` 的 hook）。所以**內容正本是 App 既有的卡片**（已對照 `data/laws`），不是這份規格。
- 規格標「待補教材」的四項（限制基本權三條件、門檻數字、五院、統籌分配稅款怎麼分），卡片裡都有完整內容，只是錄影沒展開。
- 規格把直轄市與縣市的團隊都寫成地方制度法第 56 條；條文原文：第 55 條是直轄市（副市長 3 人、14 職等、報行政院備查），第 56 條是縣市（副縣市長 2 人、13 職等、報內政部備查）。App 的兩張卡是對的。
- 規格要「單一 HTML」：不照做，做成 App 內的新模式（她的進度、同步、小貓都在 App 裡）。

## 規格原文（她那邊產生的，逐字保留）

請做出來，做不出來可以簡化

《一般民政 RPG：記憶冒險圖鑑》

請製作一款完整、可操作、適合 iPhone 手機使用的互動式考試複習遊戲。

這是給一位正在準備一般民政考試的考生使用的私人學習遊戲。

最重要的設計原則：

以圖像記憶為主，文字為輔。

考生不容易透過大量文字記憶知識，因此不能把教材直接複製成一堆文字卡片。

請用插畫、圖示、人物、場景、流程圖、顏色、視覺對比及動畫來幫助記憶。

一、視覺風格

* 可愛、溫暖、精緻的 2D RPG 冒險遊戲。
* 淺藍、奶油黃、薄荷綠、粉紅色。
* 圓角卡片、手繪風格圖示。
* 每個考點都要有專屬的視覺記憶符號。
* 每張卡片至少有一個具有意義的插畫或視覺示意圖。
* 避免大量純文字、密密麻麻的表格。
* 不要把 emoji 當成全部的插畫，應搭配 CSS、SVG 或原創簡單插圖。
* 支援手機觸控及直式瀏覽。

二、遊戲首頁

標題：《一般民政記憶冒險》

設置五個主要區域：

1. 法學知識
2. 行政法
3. 行政學
4. 地方自治
5. 國文與申論

另外設置：

* 新法更新專區
* 錯題收藏
* 圖像記憶圖鑑
* 考前總複習
* 模擬考魔王關

顯示各科學習進度及答對率。

三、必須納入的原始教材重點

以下是我提供的錄影中實際出現的重點。請保留原本的科目分類及核心意思，不要自行刪除。

A. 法學知識

1. 法律位階

* 憲法最大、法律第二、命令第三。
* 下位階不能抵觸上位階。

視覺：皇冠、法律書、命令文件三層階梯。

2. 限制基本權的條件

* 限制人民自由權利，三個條件都要過。
* 需要做成三道門的視覺關卡。
* 原始錄影未顯示三個條件的完整名稱，不可自行假裝是原始教材內容。

3. 憲法上的門檻數字

* 修憲、領土變更、罷免、彈劾。
* 各自門檻不同。
* 製作數字比較圖鑑，數字必須依正確教材補齊，不可亂填。

4. 五院的人數與任命

* 院長、委員如何產生。
* 各院人數不同。
* 製作五院人物圖鑑，並以人數及任命流程作為記憶重點。

B. 行政法

1. 行政處分是什麼

* 機關單方面對具體事件作的決定，直接生效。

視覺：政府機關發出一份文件，文件送達後產生效果。

2. 訴願到行政訴訟

* 收到處分30日內訴願。
* 訴願決定後2個月內起訴。
* 訴願期間從處分達到的次日起算30日。
* 訴願書經原處分機關送訴願管轄機關。
* 決定期限3個月，可延長一次2個月。

視覺：時間軸、30日沙漏、2個月日曆、3個月時鐘及延長按鈕。

3. 期間怎麼算

* 第一天不算。
* 最後一天遇假日往後延。

視覺：日曆第一格灰色不計算，最後一天遇假日向後移動。

4. 行政法的一般原則

* 行政行為除了守法條，還要遵守一般原則。
* 請製作不同原則的圖像辨識卡。
* 原則完整名稱需以正式教材補齊。

5. 處分錯了怎麼收回

* 違法的用撤銷。
* 合法的用廢止。
* 太離譜的直接無效。

視覺：三種不同文件處理動畫，撤銷、廢止、無效各自有不同圖示。

6. 委任、委託、委辦

* 委任：所屬下級機關。
* 委託：其他機關或民間。
* 委辦：地方自治團體。

視覺：三個人物分別把公文交給不同對象。

7. 管轄法定

* 管轄權依組織法規或行政法規定。
* 不是依法規，不得設定或變更。

相關法條：行政程序法第11條、第13條。

8. 國家賠償兩種

* 公務員行使公權力、故意或過失、不法侵害權利。
* 公共設施設置或管理有欠缺，不問有沒有過失。
* 公務員故意或重大過失時，賠償義務機關可以向其求償。
* 求償權時效2年。

視覺：左邊公務員、右邊公共設施，做成兩條不同責任路線。

相關法條：國家賠償法第2條、第3條。

C. 行政學

1. 傳統時期三大學派

* 泰勒：科學管理。
* 費堯：行政管理。
* 韋伯：官僚體制。
* 共同缺點：把組織當成封閉系統，忽略人的心理與非正式組織。

視覺：三位學者的代表人物卡，各自搭配工廠、管理者、官僚組織圖。

2. 三個「新」學派

* NPA：新公共行政，重公平。
* NPM：新公共管理，重績效。
* NPS：新公共服務，重公民。

視覺：三個不同陣營，分別用公平天秤、績效儀表板、公民人物作為圖像。

3. 黑堡宣言

* 1980年代萬斯來等人提出。
* 行政人員是公共利益的受託者。
* 和新公共行政同樣重視公平正義。

4. 領導理論演進

* 特質論 → 行為論 → 權變論 → 轉換型領導。

視覺：四階段進化路線。

5. 轉換型領導

* 柏恩斯提出，相對於交易型領導。
* 用願景與魅力激發部屬超越自我。

視覺：領導者用燈塔及光芒帶領團隊前進。

6. 公私協力：BOT家族
BOT：

* 民間興建。
* 民間營運。
* 期滿移轉給政府。

OT：

* 政府興建。
* 民間營運。
* 期滿歸還政府。

目的：

* 減輕政府財政負擔。
* 引進民間資金與經營效率。

視覺：兩條建築工程時間軸，用不同顏色區分政府及民間。

7. 組織怎麼設計
首長制：

* 一人決定。
* 行動快。
* 責任明確。

委員制：

* 行動慢。

8. 控制幅度

* 一位主管能有效指揮的部屬人數。
* 部屬越強、工作越單純，幅度越大。
* 幅度大、層級少，組織扁平化。

視覺：主管下方有不同數量的部屬，做成組織樹。

D. 地方自治

1. 中央與地方

* 自治事項自己決定。
* 委辦事項聽上級指揮。

2. 自治監督怎麼管

* 上級可以撤銷、代行處理、停職、解職。
* 自治事項有無違法發生疑義，可以聲請司法院解釋。
* 解釋前不得撤銷或停止執行。

相關法條：地方制度法第75至78條。

3. 居民的權利與義務

* 設籍在這裡的國民，就是這裡的居民。

4. 地方議會怎麼運作

* 預算只能刪減不能增加。
* 議長選舉要記名。

5. 縣市長的團隊
直轄市：

* 副市長3人，14職等。
* 報行政院備查。

縣市：

* 副縣市長2人，13職等。

6. 首長薪給與停職

E. 國文

1. 作文四段寫法
起、承、轉、合：

* 起：破題，前兩三句回應題目、表明立場，可用定義、名言或畫面開頭。
* 承：舉例。
* 轉：反思。
* 合：收束結論。

視覺：四格漫畫，從開場、舉例、轉折到結尾。

2. 公文用語

* 對上稱「鈞」。
* 平行稱「貴」。
* 自稱「本」。

上行文：

* 稱對方：鈞。
* 期望語：請鑒核、請核示。

平行文：

* 稱對方：貴。
* 期望語：請查照、請查照見復。

下行文：

* 期望語：希查照、希照辦。

視覺：上、中、下三層公文傳遞示意圖。

四、遊戲玩法

每個考點至少有四種學習模式：

1. 看圖記憶：先看插畫，再顯示極短重點。
2. 圖像配對：把圖示與正確概念配對。
3. 情境選擇：從實際行政案例判斷適用概念。
4. 間隔複習：答錯的考點自動重新出現。

例如 BOT 與 OT：
畫面出現兩個工程現場，玩家必須選出哪一個是民間興建、哪一個是政府興建。

例如撤銷與廢止：
畫面出現合法及違法的行政處分，讓玩家拖曳至正確處理方式。

例如訴願期限：
玩家必須把30日、2個月、3個月、延長2個月放到正確的時間軸。

五、視覺記憶圖鑑

每個考點都要建立專屬圖鑑卡。

卡片設計：

* 上方：一張有意義的主題插畫。
* 中間：視覺流程或對比圖。
* 下方：最多三個核心短句。
* 角落：容易混淆的考試陷阱。
* 可點擊展開完整文字解釋。

不要所有卡片都使用同一個圖示。
每個概念必須有自己的視覺聯想。

六、錯題機制

答錯時：

* 顯示正確圖像。
* 用簡短文字解釋。
* 顯示為什麼容易選錯。
* 立即再出一題類似題。

答對時：

* 獲得經驗值。
* 收集對應圖鑑。
* 連續答對可獲得額外獎勵。

七、模擬考

最後設置一個混合考試魔王關。

題目混合所有科目，不要只考剛學過的內容。

顯示：

* 正確率。
* 各科弱點。
* 最容易混淆的概念。
* 需要重新複習的圖鑑。
* 歷次成績。

八、重要製作限制

1. 必須是真正可以玩的互動遊戲。
2. 所有按鈕都必須有效。
3. 不可以只有靜態展示。
4. 文字不可過多，優先使用圖像、流程、比較及動畫。
5. 每個重要數字、期限、法條都必須保留。
6. 不可自行編造原始教材沒有提供的內容。
7. 未完整顯示的考點應標示「待補教材」，不要猜答案。
8. 法條及修法內容若需要補充，請標記為「待核對現行法規」，與原始筆記分開。
9. 盡量使用單一 HTML、CSS、JavaScript 檔案，避免外部素材依賴。
10. 請直接製作完整遊戲，不要只回覆設計企劃。

最終目標：

讓考生看到圖片，就能想起考點；看到考題，就能回想起圖片。

不是靠一直閱讀記住，而是靠視覺聯想、互動練習及反覆回憶記住。
